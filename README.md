## ✨ Why this landing?

> *Local service businesses don't need a CMS — they need a fast page that converts calls.*

| Pain | What this project does |
| --- | --- |
| Slow WordPress brochure sites | Astro static build, lightweight HTML/CSS/JS |
| Weak mobile first-impression | Responsive Tailwind layout |
| Hard to demo frontend skill | Self-contained portfolio package with live deploy |
| No clear CTA | Service blocks + contact surface ready for real leads |

## ⚡ Quick start

```bash

cd stretch-ceilings-landing
npm install
npm run dev
```

```bash

npm run preview
```
